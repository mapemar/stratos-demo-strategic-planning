# STRATOS — IFC Edition

A separate, independently navigable concept prototype for an Italy–Emerging Markets Investment Intelligence and Business Development platform.

## Access
Once GitHub Pages has deployed the folder, open:
https://mapemar.github.io/stratos-demo-strategic-planning/ifc/

## Relationship with the original STRATOS
This edition is stored in `/ifc/`. The original SACE strategic-planning application at the repository root is not modified or deleted.

## Modules
- Executive dashboard
- Italian investor map
- Country & sector outlook
- Opportunity intelligence
- Origination pipeline
- IFC product & partnership matching
- Briefings & reports

## Important limitations
This is a front-end demonstration with embedded illustrative data. It does not connect to an LLM, external databases, IFC systems, live investor mandates, or a real transaction pipeline. All sample deal sizes, stages, priorities and dashboard metrics are synthetic. Organisation names refer to real entities, but their current investment appetite and potential interest are not asserted. Replace demonstration content with validated primary-source research before using it for decisions.

## Technology
Static HTML, CSS and JavaScript. No paid hosting, server, API key or external runtime dependency. GitHub Pages can serve this folder from the existing repository.
